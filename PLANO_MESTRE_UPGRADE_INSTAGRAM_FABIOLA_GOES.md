# PARTE 2: OS 5 MAIORES VAZAMENTOS DO FUNIL

```
[ CONTEÚDO ]  ──►  [ VISITA AO PERFIL ]  ──►  [ SEGUIDOR ]  ──►  [ LEAD QUALIFICADO ]  ──►  [ VENDA / CONTRATO ]
      │                     │                     │                     │                          │
  Vazamento 1           Vazamento 2           Vazamento 3           Vazamento 4                Vazamento 5
 (Falta de gancho)     (Bio confusa)        (Falta de fixados)     (CTA sem filtro)          (Demora no contato)
```

1. **Vazamento 1 (Conteúdo ➔ Visita):** Ganchos fracos. Quem rola o feed não para em fotos de pranchas técnicas se não houver um título chamativo com uma dor real (*ex: "Sua obra pode ser parada amanhã?"*).
2. **Vazamento 2 (Visita ➔ Seguidor):** Bio genérica. O empresário de São Paulo entra no perfil e pensa *"é só mais uma arquiteta local de Belém"*, em vez de pensar *"achei a parceira ideal para a minha obra"*.
3. **Vazamento 3 (Seguidor ➔ Lead):** Falta de destaques organizados como funil. Não há uma sequência lógica de stories explicando o passo a passo da contratação.
4. **Vazamento 4 (Lead ➔ Conversa Qualificada):** Ausência de um formulário preliminar. O cliente chega perguntando *"quanto custa regularizar?"* sem enviar documento algum.
5. **Vazamento 5 (Conversa ➔ Contrato Fechado):** Falta de apresentação institucional em PDF no direct para enviar logo no primeiro contato.
